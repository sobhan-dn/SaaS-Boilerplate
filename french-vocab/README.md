# واژه‌نامهٔ فرانسه به فارسی — A1 تا B2

فایل `Francais-Farsi-A1-B2.pdf` یک واژه‌نامهٔ کامل فرانسه به فارسی است: هر واژه با
**املای فرانسه**، **تلفظ با حروف فارسی** و **معنی** آمده و همه‌چیز بر پایهٔ سطح‌های
CEFR (از A1 تا B2) و موضوع دسته‌بندی شده است.

## داخل PDF چه چیزی هست؟

| بخش | توضیح |
| --- | --- |
| جلد و فهرست مطالب | فهرست کلیک‌پذیر همهٔ سطح‌ها و موضوع‌ها |
| راهنمای تلفظ | ۹ نکتهٔ کلیدی + جدول صداهای فرانسه و معادل فارسی آن‌ها |
| A1 — مبتدی | ۲۲ موضوع: احوال‌پرسی، اعداد، خانواده، خوراک، شهر، فعل‌ها و صفت‌های پایه… |
| A2 — پایه | ۱۸ موضوع: خرید، رستوران، سفر، سلامتی، احساسات، فناوری، کارهای خانه… |
| B1 — متوسط | ۱۶ موضوع: کار، تحصیل، مسکن، محیط زیست، رسانه، اداری و حقوقی، بیان نظر… |
| B2 — مستقل | ۱۶ موضوع: سیاست، اقتصاد، عدالت، علم، اقلیم، روان‌شناسی، پیوندواژه‌های پیشرفته… |
| پیوست‌ها | عبارت‌های ضروری روزمره، اصطلاح‌های رایج، فعل‌های بی‌قاعدهٔ کلیدی |
| فهرست الفبایی | همهٔ واژه‌های فرانسه با شمارهٔ صفحه |

## قرارداد تلفظ

تلفظ‌ها بر پایهٔ فرانسهٔ معیار (پاریس) نوشته شده‌اند. چند نکته که در صفحهٔ «راهنمای تلفظ»
هم توضیح داده شده است:

- صدای `u` (در `tu`) بین «او» و «ای» است: لب‌ها گرد، زبان جلو.
- صداهای تودماغی با «ن» نوشته شده‌اند (`bon` ← «بُن»)، ولی این «ن» کامل ادا نمی‌شود.
- علامت ساکن نشان‌دهندهٔ خوشهٔ هم‌خوانی است (`trois` ← «تْروآ»).
- حرف `r` از ته گلو و نزدیک به «غ» تلفظ می‌شود.

## ساختن دوبارهٔ فایل

```bash
pip install fpdf2 uharfbuzz fonttools
python3 build_pdf.py                 # می‌سازد: Francais-Farsi-A1-B2.pdf
python3 export_data.py               # می‌سازد: خروجی CSV و TSV مخصوص Anki
```

اسکریپت پیش از ساخت، دو بررسی انجام می‌دهد: نویسه‌هایی که در فونت وجود ندارند و
واژه‌هایی که بیش از دو بار در سطح‌های مختلف تکرار شده‌اند را گزارش می‌کند.

## ساختار پوشه

```
french-vocab/
├── build_pdf.py          سازندهٔ PDF (چیدمان، جدول‌ها، فهرست‌ها)
├── export_data.py        خروجی CSV و TSV
├── data/
│   ├── a1.py b1.py       داده‌های واژگان هر سطح
│   ├── a2.py b2.py
│   ├── appendices.py     عبارت‌ها، اصطلاح‌ها، فعل‌های بی‌قاعده
│   └── guide.py          متن و جدول راهنمای تلفظ
└── fonts/                فونت وزیرمتن (مجوز SIL OFL)
```

برای افزودن واژه کافی است یک سه‌تایی `(فرانسه، تلفظ، معنی)` به فهرست `words` در فایل
سطح موردنظر اضافه کنید و دوباره اسکریپت را اجرا کنید؛ شماره‌گذاری صفحه‌ها، فهرست مطالب
و فهرست الفبایی خودکار به‌روز می‌شوند.

اتصالی فارسی و راست‌به‌چپ‌سازی با موتور HarfBuzz انجام می‌شود.
